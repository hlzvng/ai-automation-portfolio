# AI 업무 자동화 포트폴리오 — 김희정

온라인 교육 플랫폼 Fastcampus(데이원컴퍼니)에서 콘텐츠 PM으로 일하며, 반복되는 기획 업무를 AI 에이전트로 직접 설계하고 운영한 사례를 모았습니다.

코드를 잘 짜는 것보다 **어떤 판단은 사람에게 남기고, 무엇을 기계에 넘길지 정하는 일**에 집중했습니다. 사례마다 실패와 한계도 그대로 적었습니다.

## 일하는 방식
- **사람은 고르고, 기계는 준비한다.** 조사·초안·정리는 자동화하고, 채택·발송·승인은 사람이 한다.
- **판단 기준은 코드 밖에 둔다.** 성공 규칙과 사례를 별도 지식베이스로 분리해, 기준이 바뀌어도 자동화를 고치지 않는다.
- **조용한 실패를 가장 경계한다.** 무인 실행은 실패 시 가시성이 신뢰를 만든다.
- **실패한 버전도 자산이다.** 멈춘 프로젝트는 학습 기록을 남기고 다음 버전의 설계 근거로 쓴다.
